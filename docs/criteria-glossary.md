# Criteria glossary

Public page at `/criteres` listing every criterion, grouped as on the urban unit
detail page, with a plain-language description and a link to its ranking when
it has one.

The descriptions are written once in the glossary, keyed by criterion code: the
criteria rows are created by the importers from the vendored data, which carry
no text. A criterion without an entry falls back to its stored description, and
is listed without text if it has none. The source is set per group, with a few
criteria overriding it. A new criterion needs its entry in the
glossary; a group missing from the display order comes after the known ones.
