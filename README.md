# Pondeo

A website to compare French areas (cities, departments, regions, ...) according to multiple criteria.

## Installation

**Requirements:** run `bin/doctor` to check.

```bash
make install
```

Then visit <https://pondeo.localhost:8443> (<http://pondeo.localhost:8089> redirects there).
